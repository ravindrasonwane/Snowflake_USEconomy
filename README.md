# Snowflake_USEconomy

## 📊 US Economic Analytics Dashboard using Snowflake Cortex & Streamlit

### Dashboard Link : https://app.snowflake.com/

---

## 📌 Problem Statement

This dashboard provides insights into key US macroeconomic indicators such as inflation, unemployment rate, and mortgage interest rates using Snowflake Cortex AI and Streamlit integration. By analyzing these economic metrics over time, analysts and decision-makers can identify trends, monitor economic health, and generate AI-powered insights.

Since economic indicators fluctuate frequently, this dashboard helps users understand changes in inflation, labor market conditions, and borrowing costs through interactive visualizations and natural language querying.

Additionally, the integration of Snowflake Cortex enables users to ask business questions in plain English and receive AI-generated economic analysis, improving accessibility and decision-making efficiency.
